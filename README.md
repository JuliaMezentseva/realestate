# Прототип Skillaz Start для ИНКОМ-Недвижимость

Демо-прототип модуля адаптации Skillaz Start, наполненный контентом под агентство
недвижимости: план адаптации специалиста по вторичному рынку, роли наставника и
учебно-методического центра, контрольные точки и риски, настроенные под реальные
точки отвала новичков в отрасли.

Методика и обоснование решений — в [METHOD.md](METHOD.md).

> Все данные в прототипе — демонстрационные. Имена сотрудников, названия отделений,
> адреса, суммы и показатели вымышлены и не отражают реальные данные клиента.

## Роли в прототипе

| Роль | Точка входа | Что показывает |
|---|---|---|
| Сотрудник | `employee/adaptation.html` | План новичка: маршрут, цели, подцели, контрольные точки |
| Руководитель | `manager/team.html` | Команда, риски по новичкам, проведение контрольных точек |
| Наставник | `assistant/plan.html` | Свои задачи в чужом плане: подтверждение шагов, оценочные листы |
| HR-админ | `hr/plans.html`, `hr/template.html` | Шаблоны планов, назначенные планы, очередь назначения, справочники |
| Кандидат | `candidate/adaptation.html` | Пребординг до первого дня |

Стартовая страница — `index.html`.

## Проверка страниц прототипа

`render-check.js` — прогоняет HTML-страницу прототипа через Babel (проверка синтаксиса
`<script type="text/babel">`) и рендерит её в jsdom через настоящий React 18, проверяя,
что `#root` не пустой и не было JS-ошибок.

### Установка (один раз)

```
npm install jsdom @babel/core @babel/preset-react react@18.3.1 react-dom@18.3.1
```

### Запуск

```
node test/render-check.js hr/template.html
node test/render-check.js hr/plan.html --query "kind=assigned&id=onboarding"
```

`interaction-test.js` и `interaction-*.js` — тот же харнесс с имитацией кликов
(переключение свитчей, открытие модалок) для проверки интерактивных сценариев.

Известные ограничения харнесса (унаследованы от исходного прототипа, не связаны
с контентом ИНКОМ): `hr/vacancy-new.html` не рендерится в jsdom — страница использует
`IntersectionObserver`, которого в jsdom нет; часть `interaction-*.js` содержит
устаревшие ассерты и падает так же, как в исходном репозитории.
